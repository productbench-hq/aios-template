## Guidelines for Pro/Con Summary

1. **Be specific** - Arguments should reference the actual request, not generic statements
2. **Group by theme** - Don't just list criteria, group related arguments together
3. **Counter-arguments matter** - For each major pro, consider if there's a counter in the cons
4. **Decision hinges on** - These should be answerable questions that would resolve the decision
5. **My Read** - Be honest about the tradeoffs, acknowledge uncertainty
6. **Reference the full doc** - User can go deeper if they want the reasoning behind each point
