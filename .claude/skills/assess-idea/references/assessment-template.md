## Confidence Level Reference

| Level | Marker | Use When |
|-------|--------|----------|
| Evidence-Based | 🟢 | Data, research, metrics, validated facts |
| Committed | 🔵 | Roadmap items, contracts, stated decisions |
| Assumed | 🟡 | Logical inference, stated as assumption |
| Blind | 🔴 | No data, no reasonable basis to guess |
