# Starter KPI catalog, version 1

Offer this fixed list when an organization has no governed catalog available. It becomes the active list only when accepted in onboarding. Use IDs in estimates. Bind the relevant definitions to local reports and record the population, period, currency, and exclusions. Expressions derived for a calculation may be shown as inputs or outputs.

| ID | KPI | Definition and unit |
| --- | --- | --- |
| C01 | Cart-to-order conversion | Unique cart shoppers placing a paid order / unique cart shoppers in the same cohort and agreed conversion window, % |
| C02 | Checkout completion | Unique checkout starters placing a paid order / unique checkout starters in the same cohort and agreed conversion window, % |
| C03 | Paid orders | Count of distinct paid order IDs in the period |
| C04 | Average order value | Net sales excluding VAT / paid orders, currency per order, using a consistent refund policy |
| C05 | Net revenue | Sales net of discounts, refunds and VAT in the period, currency |
| C06 | Gross margin | (Net revenue − cost of goods sold) / net revenue, % |
| C07 | Contribution per order | (Net revenue − COGS − incremental variable costs) / paid orders, currency per order |
| C08 | Customer retention | Starting customer cohort still active at period end / starting cohort, %; define active and observation window |
| C09 | Paid customer conversion | Eligible prospects becoming paying customers / eligible prospects in the cohort and conversion window, % |
| O01 | Handling time per case | Total active handling hours / completed cases, hours per case |
| O02 | Cost per case | Relevant operating cost / completed cases, currency per case; record included costs |
| O03 | Incident rate | Incidents / defined units of exposure in period, incidents per unit |
| O04 | Engineering effort per change | Active engineering person-hours / completed comparable changes, hours per change |
| O05 | Operating spend | Actual operating expenditure in the agreed cost category and period, currency |

Use local reporting definitions when the organization selects its own catalog. When no entry fits, show the gap, offer a justified existing proxy, or ask the metric owner to approve a catalog amendment. Keep proposed additions outside the active estimate until approved. Delivery rates, effort assumptions, ROI, payback, and break-even can be calculation inputs or outputs without becoming catalog KPIs.
